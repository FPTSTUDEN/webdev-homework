# Individual Assignment – Web Application

The objective of this assignment is to build a functional web application.

## Topic

Create an application that displays student restaurants in Finland and their daily and weekly menus. The application should use a REST API similar to the one used during the lessons.

## Minimum Requirements – Grade 1 (12/40)

- Restaurants are listed in some way.
- The user can select whether they want to view the daily or weekly menu of a restaurant, and the selected menu is displayed.
- The application is published on the users.metropolia.fi server or another publicly accessible server.
- The source code is available on GitHub or a similar service.
- Good Git practices are followed.

## Additional Requirements for Higher Grade

You do not need to implement everything on this list. The more advanced and well-implemented features you include, the higher the potential grade.

- All minimum requirements are fulfilled.
- User login and registration.
- Users can select their favorite restaurant.
- Users can update their personal information.
- Users can upload a profile picture.
- Restaurants can be filtered, for example, by city, service provider, or other criteria.
- Restaurants are listed clearly and logically.
- Restaurants are displayed on a map.
- The nearest restaurant is highlighted.
- Additional features of your own choice.

## Technical Requirements

### JavaScript

- The front-end application logic must be implemented using vanilla JavaScript.
- The use of ES6+ features and practices introduced in the JavaScript exercises is recommended.
- The use of front-end frameworks or libraries such as Angular, React, or jQuery is not allowed.
- The use of CSS frameworks such as Bootstrap is not allowed.

### Programming Practices

Follow good programming practices, including:

- logical and descriptive naming conventions
- consistent indentation and code formatting
- clear and well-structured code

### HTML and CSS

- HTML and CSS should be implemented professionally and validated.
- The user interface should be clean and easy to understand.
- Responsive design is considered a plus.
